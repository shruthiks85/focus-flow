# Focus Flow

Build a modern task tracking app. Users should be able to add , delete, update a task. User should be able to see the list of tasks created.  Create a responsive web UI and mobile app.



Include these fields for each task: Priority with options to choose: IU, UNI, INU, and NINU, Subject, due date, action plan, and completion date columns 



Include a Priority legend to show of each type of task added

 

The app should have a clean, mobile-friendly design and feel like a real consumer product. For Reference Excel attached
